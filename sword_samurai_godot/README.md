# Sword Samurai — menu de RPG para Godot 4

Abra `project.godot` no Godot 4 e execute com F6/F5. A cena oferece uma tela de título 16:9 em pixel art, partículas de sakura animadas, animação suave do título, interface com feedback sonoro, painel de créditos e menu de opções.

## Áudio e opções

Os efeitos originais ficam em `assets/`: hover de botão, confirmação com katana, transição de painel e ambiência noturna em loop. O menu de opções controla volumes, mudo, pétalas e tela cheia; as preferências são guardadas em `user://settings.cfg`. Use setas/Tab e Enter para navegar, Esc para fechar painéis. A saída pede confirmação.

Para ligar o botão Iniciar à fase, salve a cena jogável como `game.tscn` na raiz do projeto.
